# 🌍 WanderAI - Production-Ready AI Travel Planner Web Application

**WanderAI** is a modern, high-performance, 100% FREE full-stack web application designed to generate customized, day-by-day travel itineraries in seconds. Built with **Next.js 15 (App Router)**, **TypeScript**, **Tailwind CSS**, **Shadcn UI**, **OpenAI API**, **OpenStreetMap & Leaflet**, and **Firebase (Auth & Firestore)**.

---

## ✨ Features

- 🔐 **Google Authentication**: Seamless Google Sign-In powered by Firebase Authentication with automatic user profile syncing to Firestore.
- 🤖 **AI-Powered Itineraries**: Instant custom travel plans generated by OpenAI (`gpt-4o-mini`) using structured JSON schema output validation.
- 🎯 **Tailored Travel Parameters**:
  - Destination Search with **OpenStreetMap Nominatim API**.
  - Trip Duration (1–14 days) and Start Date selector.
  - Budget Tiers (**Cheap $**, **Moderate $$**, **Luxury $$$**).
  - Travel Companion Groups (**Solo**, **Couple**, **Family**, **Friends**).
  - Travel Styles (**Balanced**, **Cultural**, **Adventure**, **Relaxation**, **Foodie**).
- 📍 **Interactive OpenStreetMap**: Color-coded Leaflet location markers for hotels (Purple), attractions (Pink), and restaurants (Amber) with InfoWindow popups and turn-by-turn directions links (`https://www.openstreetmap.org/?mlat={lat}&mlon={lon}`).
- 🏨 **Hotel Recommendations**: Handpicked stays with pricing, ratings, and OpenStreetMap links.
- 💾 **Firestore Trip Persistence**: Save AI itineraries to your account, view saved trips, and manage/delete trips with modal confirmation.
- 📊 **Traveler Dashboard**: Filter saved trips by destination or budget, search in real time, sort by date/duration, and review travel summary metrics.
- 🌓 **Theme Support**: Seamless Light/Dark mode toggling using `next-themes`.
- ⚡ **Optimized Performance**: Next.js 15 App Router, Image optimization (`next/image`), rate-limiting protection, and TypeScript strict safety.

## 🚀 Getting Started

### Prerequisites

- **Node.js**: `v18.17.0` or higher
- **npm** / **yarn** / **pnpm**

### 1. Clone & Install Dependencies

```bash
git clone https://github.com/your-username/trip-planner-ai.git
cd trip-planner-ai
npm install
```

### 2. Environment Variables Setup

Create a `.env.local` file in the root directory and populate your API credentials:

```ini
# Firebase Client Environment Variables
NEXT_PUBLIC_FIREBASE_API_KEY=your_firebase_api_key
NEXT_PUBLIC_FIREBASE_AUTH_DOMAIN=your_project_id.firebaseapp.com
NEXT_PUBLIC_FIREBASE_PROJECT_ID=your_project_id
NEXT_PUBLIC_FIREBASE_STORAGE_BUCKET=your_project_id.appspot.com
NEXT_PUBLIC_FIREBASE_MESSAGING_SENDER_ID=your_messaging_sender_id
NEXT_PUBLIC_FIREBASE_APP_ID=your_app_id

# OpenAI API Key (Server-side)
OPENAI_API_KEY=your_openai_api_key

# Google Maps Platform Key
NEXT_PUBLIC_GOOGLE_MAPS_API_KEY=your_google_maps_api_key
```

### 3. Run Development Server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your web browser to test the application.

## 🔒 Security & Optimization Best Practices

1. **API Key Safety**: `OPENAI_API_KEY` is restricted strictly to server-side Next.js API routes (`app/api/generate-trip/route.ts`).
2. **Rate Limiting**: Server route incorporates IP rate-limiting to prevent API quota abuse.
3. **Structured Outputs**: OpenAI response format enforces pure JSON output, parsed and validated with Zod before delivery.
4. **Fallback Mechanism**: High-quality demo fallback generation ensures zero downtime if OpenAI API keys are unconfigured or rate-limited.
5. **Caching**: Google Places API queries utilize in-memory client caching to reduce redundant billable API calls.
