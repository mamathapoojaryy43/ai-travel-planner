# 🌍 WanderAI – AI Travel Planner

WanderAI is an AI-powered travel planner built with Next.js, TypeScript, Firebase, and OpenAI. It helps users generate personalized travel itineraries, explore destinations on interactive maps, and save trips securely in the cloud.

## ✨ Features

- 🔐 Firebase Authentication (Google & Email)
- 🤖 AI-generated travel itineraries
- 📍 OpenStreetMap integration
- 🏨 Hotel and attraction recommendations
- 💾 Save and manage trips with Firestore
- 🌙 Light & Dark mode
- 📱 Responsive design

## 🛠️ Tech Stack

- Next.js 15
- TypeScript
- Tailwind CSS
- Firebase Authentication
- Cloud Firestore
- OpenAI API
- OpenStreetMap & Leaflet

## 🚀 Installation

```bash
git clone https://github.com/your-username/wanderai.git
cd wanderai
npm install
npm run dev
```

Create a `.env.local` file and add your Firebase and OpenAI API keys.
